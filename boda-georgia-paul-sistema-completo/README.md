# Georgia & Paul — Sistema completo de boda

Sistema Next.js listo para Vercel.

Incluye:
- Portada premium con contador al 17/10/2026 18:00 Ecuador.
- Fotos con Vercel Blob.
- Galería.
- Cócteles con pedidos centralizados.
- Dos usuarios bartender.
- Cola compartida.
- Estados Pendiente / Preparando / Entregado.
- Notificaciones Web Push para los bartenders.
- Control central de bebidas alcohólicas y espera configurable.
- PWA para usar `/barra` como mini app en celular.

Lee `GUIA_PRUEBAS.md`.

## Importante

No subas credenciales privadas a GitHub.
Usa `.env.example` como referencia y configura los valores reales directamente en Vercel.
